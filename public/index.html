Run Video Downloader Locally

Run Video Downloader directly on your local machine with Linux without using server resources. Fully self-contained with bundled Node.js and dependencies.

Platform: Linux x86_64
Package: Standalone Portable (.tar.gz)
Attribution: Zero server/user fingerprint metadata
Hint: slija

Quick Start on Linux:

  1. Extract the .tar.gz archive into any folder.
  2. Double-click VideoDownloader.desktop (or run ./start.sh).
  3. Opens automatically at http://127.0.0.1:3000.

1-Click Browser Tools

Zero installation needed! Drag the button below to your browser's Bookmarks/Favorites bar. Whenever you are on YouTube, Twitter, Instagram, or Reddit, simply click the bookmark to instantly download the media.

⬇️ Download Media

⬆️ Drag this button directly to your browser's Bookmarks bar

How it works:

  1. Make sure your browser bookmarks bar is visible (Ctrl+Shift+B or Cmd+Shift+B).
  2. Drag the "⬇️ Download Media" button above into your bookmarks bar.
  3. Go to any video on YouTube, Reddit, Instagram, or Twitter and click that bookmark!
